# DJ's Revolution - Prototipo de Presentación

Plataforma social para DJs Cristianos donde pueden subir, compartir y descargar mixes de audio y video.

## Objetivo
Este repositorio contiene el **prototipo visual estático** (HTML, CSS y JS) que servirá para la presentación al cliente. 
El diseño simula un feed tipo Facebook especializado para medios (audio y video), con estética moderna y oscura (Dark Mode), ideal para la comunidad DJ.

## Tecnologías Utilizadas en el Prototipo
- HTML5
- CSS3 (Vanilla CSS, Glassmorphism, CSS Variables)
- JavaScript (Interacciones básicas de UI)
- Font Awesome (Iconografía)
- Google Fonts (Outfit)

## Futuro del Proyecto
Este código está estructurado para ser integrado y convertido en un **Tema o Plugin de WordPress**. Una vez aprobado el diseño por el cliente, los archivos HTML serán segmentados (header.php, footer.php, index.php) y se integrarán con el CMS para permitir registro de usuarios, subida real de contenido y Custom Post Types para los Mixes.

## Cómo visualizar
1. Clona este repositorio o descárgalo como ZIP.
2. Abre el archivo `index.html` en tu navegador web. No requiere servidor local para su visualización inicial.
